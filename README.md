# Финансовый ассистент

Интеллектуальный ассистент для анализа и прогнозирования личных финансов: учёт доходов и
расходов, импорт операций из файла, автоматическая категоризация, аналитика с графиками,
поиск повторяющихся платежей, прогноз расходов методами машинного обучения и рекомендации
по планированию бюджета.

## Технологии

| Слой | Технология |
|---|---|
| Веб-фреймворк | FastAPI, Uvicorn |
| Интерфейс | Jinja2, Bootstrap 5, Chart.js (локально, без CDN) |
| База данных | SQLAlchemy 2.0, Alembic, SQLite (с возможностью перехода на PostgreSQL) |
| Анализ и ML | pandas, scikit-learn, statsmodels |
| Курсы валют | API Национального банка Республики Беларусь |
| Качество кода | pytest, ruff |

## Структура проекта

  services/        бизнес-логика
  integrations/    клиенты внешних сервисов (курсы НБРБ, ЦБ РФ, currency-api)
  utils/           вспомогательные функции
  api/             REST API (JSON), документация на /docs

## Установка и запуск (Windows, PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env        # при необходимости отредактировать
.\.venv\Scripts\python.exe -m app.cli init-db   # миграции + стартовые категории
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

После запуска:

- веб-интерфейс: <http://127.0.0.1:8000>
- документация API (Swagger): <http://127.0.0.1:8000/docs>

## Проверка кода

```powershell
.\.venv\Scripts\python.exe -m pytest            # тесты
.\.venv\Scripts\python.exe -m ruff check .      # линтер
.\.venv\Scripts\python.exe -m ruff format .     # форматирование
```

## Переход на PostgreSQL

Установить драйвер (`pip install "psycopg[binary]"`), указать в `.env`
`DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/finance`
и выполнить `python -m app.cli init-db`. Код приложения менять не нужно.

## Курсы валют

Операции в USD пересчитываются в BYN по курсу на дату операции. Порядок получения курса:

1. Кэш — курс, уже полученный ранее на эту дату (таблица `exchange_rates`).
2. Онлайн-источники по очереди: **НБРБ** → **ЦБ РФ** (кросс-курс USD/RUB ÷ BYN/RUB) →
   **currency-api** (рыночный курс, два зеркала).
3. Если все источники недоступны (нет интернета), пользователь выбирает:
   ввести курс вручную или взять курс из истории системы — ближайший известный курс
   (из кэша или прошлых USD-операций) не дальше `RATE_HISTORY_MAX_DAYS` дней (по умолчанию 7).

Источник курса сохраняется в каждой операции (`rate_source`).

## Модель данных

| Таблица | Назначение |
|---|---|
| `categories` | Категории доходов и расходов (название, тип, цвет, признак системной) |
| `category_rules` | Ключевые слова для автоматической категоризации |
| `transactions` | Операции: дата, тип, сумма, валюта, курс, сумма в BYN, описание, категория |
| `exchange_rates` | Кэш курсов НБРБ (BYN за 1 единицу валюты на дату) |

Суммы хранятся в `Numeric(12, 2)` (точная десятичная арифметика), сумма операции всегда
положительна, направление определяется типом. Вся аналитика считается в BYN по полю
`amount_byn`.
